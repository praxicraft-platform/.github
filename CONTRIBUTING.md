# Contributing to Praxicraft GitHub profile

Thanks for helping improve Praxicraft Assess open source.

Please read our [Code of Conduct](./CODE_OF_CONDUCT.md). Report unacceptable behavior to [support@praxicraft.com](mailto:support@praxicraft.com).

## How to contribute

Update profile README / org meta carefully — this repo is public-facing branding. Open a PR with a short description of the change.
